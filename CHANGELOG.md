# История изменений — Небосвод

Формат записи упрощённый, человеческим языком. Верхняя строка — последний исходящий релиз.

**Текущая версия:** 0.10 (2026-09-16)

---

## v0.10 — 2026-09-16
- **Пакетный запрос погоды** — `GET /api/weather?city_ids=1,2,3` отдаёт погоду для множества городов одним запросом (один вызов к Open-Meteo на всю пачку). Главная страница больше не делает по запросу на каждый город — при 40+ городах это в разы быстрее и заметно легче и для сервиса, и для браузера.
- **Stale-while-error** — если Open-Meteo недоступен, сервис не отдаёт ошибку и не оставляет пустые плитки: он показывает последние успешно полученные данные и помечает их как `stale` (в JSON — поля `stale`, `stale_age`; на плитке — метка «устарело»). Если данных нет вообще — только тогда честная ошибка.
- **Порядок плиток для зарегистрированных** — в настройках появился блок «Порядок плиток»: города расставляются стрелками ↑/↓, порядок сохраняется в базе (колонка `position` у `user_cities`) и применяется на главной. Миграция старых баз выполняется автоматически.
- **API списка городов** — `GET /api/all-cities` отдаёт все города сервиса (id, имя, alias, координаты, часовой пояс); работает как синоним `/api/cities`.
- Документация: в README и на странице помощи описаны пакетный запрос, список городов, поведение при недоступном источнике и настройка порядка плиток.
- Скрипт обновления: показывает список контейнеров и спрашивает ID, сам определяет каталог установки и имя сервиса.

## v0.9 — 2026-08-30
- Добавлен пример интеграции **MajorDoMo** на страницу помощи — рабочий код метода `getWeather` (рассвет/закат, погода сейчас, на день и на ночь).
- Добавлен скрипт обновления **уже установленного контейнера** (`install/nebosvod-update.sh`) — команда одной строкой, без переустановки и без потери пользователей и городов.
  - Скрипт **сам просит ID контейнера** (показывает список LXC), определяет рабочую директорию сервиса (`/opt/nebosvod` или `/opt/weather-proxy`) и имя сервиса (`nebosvod`/`weather`/`weather-proxy`).
  - **Подробный вывод процесса** обновления: бэкап БД и настроек, обновление кода (git fast-forward или замена файлов), перезапуск сервиса, проверка API.
- В README — раздел «Обновление».
- Убраны устаревшие установочные скрипты старой структуры (`nebosvod-install.sh`, `nebosvod.sh`).

## v0.8 — 2026-08-17
- **Клиентский кэш погоды** (localStorage): карточки городов показываются сразу из кэша при повторном визите, свежие данные догружаются фоном. Нет пустых плиток.
- **Исправлен доступ к Open-Meteo**: сервер больше не обходит прокси — без него из LXC-контейнера наружу ходить нельзя. Все города теперь обновляются.
- **Мобильные фиксы:**
  - секция городов в модалке настроек снова видна и скроллится (раньше схлопывалась в ноль на телефоне);
  - модалка настроек на мобильном скроллится целиком одним потоком (без зажатой полосы списка);
  - модалка прогноза погоды компактнее на маленьких экранах.
- README — добавлено официальное зеркало `nebosvod.smkot.ru`.

- README — команда установки одной строкой и официальный сайт `nebosvod.amofess.ru`.

## v0.6 — 2026-08-16 (зарождение)
- **Первый публичный коммит** — погодный сервис-прокси поверх Open-Meteo на чистом Python stdlib, без внешних зависимостей.
- Целевая установка — LXC-контейнер на Alpine (заменяет Docker).
- Отдаёт данные в JSON для людей, скриптов и умного дома.
