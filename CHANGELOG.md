# История изменений — Небосвод

Формат записи упрощённый, человеческим языком. Верхняя строка — последний исходящий релиз.

**Текущая версия:** 0.9 (2026-08-30)

---

## v0.9 — 2026-08-30
- Добавлен пример интеграции **MajorDoMo** на страницу помощи — рабочий код метода `getWeather` (рассвет/закат, погода сейчас, на день и на ночь).
- Добавлен скрипт обновления **уже установленного контейнера** (`install/nebosvod-update.sh`) — команда одной строкой, без переустановки и без потери пользователей и городов.
- В README — раздел «Обновление».
- Убраны устаревшие установочные скрипты старой структуры (`nebosvod-install.sh`, `nebosvod.sh`).

## v0.8 — 2026-08-17
- **Клиентский кэш погоды** (localStorage): карточки городов показываются сразу из кэша при повторном визите, свежие данные догружаются фоном. Нет пустых плиток.
- **Исправлен доступ к Open-Meteo**: сервер больше не обходит прокси — без него из LXC-контейнера наружу ходить нельзя. Все города теперь обновляются.
- **Мобильные фиксы:**
  - секция городов в модалке настроек снова видна и скроллится (раньше схлопывалась в ноль на телефоне);
  - модалка настроек на мобильном скроллится целиком одним потоком (без зажатой полосы списка);
  - модалка прогноза погоды компактнее на маленьких экранах.
- README — добавлено официальное зеркало `nebosvod.smkot.ru`.

## v0.7 — 2026-08-16
- README — раздел **«Об установке и публичных копиях»**: разрешение ставить сервис на свои HomeLab, просьба не убирать строку благодарности, приглашение добавлять публичные копии в README.
- README — команда установки одной строкой и официальный сайт `nebosvod.amofess.ru`.
- Самодостаточный установочный скрипт **`install/nebosvod-standalone.sh`** (одна команда, без community-scripts): динамический выбор alpine-шаблона, клон с GitHub по умолчанию.
- Логотип стал кликабельным — переход «главная ↔ помощь» в той же вкладке.
- Страница помощи для умного дома, кнопка в настройках, разделители 94%.
- Статус-строка: инфо слева, ссылка-благодарность справа.
- Поиск в настройках, защита от дублей городов, донат-ссылка.

## v0.6 — 2026-08-16 (зарождение)
- **Первый публичный коммит** — погодный сервис-прокси поверх Open-Meteo на чистом Python stdlib, без внешних зависимостей.
- Целевая установка — LXC-контейнер на Alpine (заменяет Docker).
- Отдаёт данные в JSON для людей, скриптов и умного дома.
